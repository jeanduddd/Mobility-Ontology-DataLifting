# Mobility-Ontology-DataLifting

This repository contains the resources and tools to create a knowledge graph from urban mobility data.
### Project Structure

### 1. [Mobility Ontology](./Mobility-Ontology)

This folder contains the ontology files.<br>
Its is composed of the main ontology file and its associated vocabulary.

### 2. [Mobility Data Lifting](./Mobility-Data-Lifting)

This folder contains the datalifting tool made to convert mobility indicators data into RDF turtle triples.<br>
Relying on the [Morph-xR2RML engine](https://github.com/frmichel/morph-xr2rml/tree/master), it generates a knowledge graph based on the defined ontology.

[Click here to access the full documentation for the Data Lifting tool](./Mobility-Data-Lifting/README.md)
